### What I've built

**AI Assisted UGC Moderation Platform** — *Social Native*
Full stack platform moving brand user generated content through premod, tagging, and QA, with Claude classifying against each brand's own guidelines. Cut per image review from **15 minutes to seconds**.

**Automated UGC Product Detection** — *Bloom Nutrition*
Computer vision pipeline that samples creator videos frame by frame and logs which product appears in each, replacing a daily manual tagging task. Aggregates detections across frames with a confidence floor, so an unlabeled post beats a confidently wrong one.
`Roboflow` `FFmpeg` `Node.js` `PostgreSQL` `Next.js`

**Invoice Intake & Bookkeeping Automation** — *Janey Health*
n8n workflow: inbox → Claude reads the PDF → filed by vendor in Drive → matching unpaid bill opened in QuickBooks. Stops deliberately at unpaid so a human approves every dollar.
`n8n` `Claude` `QuickBooks API` `Google Workspace`
